# Rules, Timing & Penalties
## Official (Rulebook)
2–3 members, same institution, unique team name, no individuals. R1 elimination quiz, strict time, no negative marking unless organizers specify, no phones/devices/help, malpractice = disqualification. R2 prep 10–15 min, present 2–3 min, provided info only, no internet/mobile unless permitted. R3 prep 5–10 min, 3-min pitch, cross-questions. Be on time; judges final; misconduct = disqualification; ties via tie-breaker.
## Proposed (additional, editable in Organizer)
Warning for minor disruption; repeated disruption may cost points or removal with organizer approval; overtime deduction (default 0, set by organizer); all penalties announced beforehand and logged; only the organizer changes scores/reveals answers/advances teams.
